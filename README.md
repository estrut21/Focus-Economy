# Focus-Economy
Your attention is like money so you tradeoff your time in order to receive rewards.
Focus Economy is a Pomodoro timer that turns focused time into a reward system.

In Microeconomics we learned that time is money and that the time you spend doing a task is a tradeoff for something else. So I built a credit card cash back system for your time so you can still get some cash "rewards back"

What it features is the timer, and rewards after completing a session.

How it works:
1. Start the focus timer.
2. work until the timer reaches zero and earn 10 coins
3. jar will fill up.
4. Spend coins on rewards in the reward shop.
